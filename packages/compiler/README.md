# @benosjs/compiler

The Babel-based TypeScript/JSX transform for Benos. It emits inert template and
component descriptors, source maps, development diagnostics, and the compact
production plan encoding used by `@benosjs/dom`.

Applications normally use it through [@benosjs/vite](../vite/README.md). Direct
transforms are available through the documented compiler API.

See the [compiler design](../../docs/architecture/compiler.md).
