# Benos app

![Benos logo](https://raw.githubusercontent.com/benosjs/benos/main/assets/benos-logo.png)

This app was created with `create-benos`. It uses the public Benos package
roots, TypeScript/TSX, Vite, ESLint, Prettier, and Vitest. The starter includes
a signal counter that demonstrates run-once components, plus an interactive
keyed list. Its colors and logo follow the system light or dark theme.

```sh
__PACKAGE_MANAGER__ install
__PACKAGE_MANAGER__ run dev
```

The starter demonstrates signals, a component, and `<For>`. Read the [getting
started guide](https://github.com/benosjs/benos/blob/main/docs/getting-started.md),
[API reference](https://github.com/benosjs/benos/blob/main/docs/api-reference.md),
or [React migration guide](https://github.com/benosjs/benos/blob/main/docs/react-migration.md).
