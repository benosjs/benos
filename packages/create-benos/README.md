# create-benos

Scaffold a TypeScript/TSX Benos application with Vite, Vitest, ESLint,
Prettier, signals, components, `<Show>`, and `<For>`.

```sh
npm create benos@latest my-app
```

The CLI detects npm, pnpm, Yarn, and Bun. Use `--yes` for a confirmed
non-interactive overwrite and `--git` when Git initialization is wanted.
