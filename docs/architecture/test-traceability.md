## Deterministic disposal evidence

The two L disposal tests inspect the actual linked-list subscriber counts and actual render/user/mount queue counts before and immediately after disposal, while the source signal remains reachable. The private inspection hook exposes a mirror `Set` only for testing subscription order; link and unlink operations keep it in sync with the graph. The tests assert zero retained edges and zero queued jobs before the enclosing batch flushes. This proves prompt graph and queue detachment without depending on garbage collection timing. The test for a middle entry in a 1,000-effect queue also asserts removal before flush and verifies that the 500 surviving effects run exactly once.
