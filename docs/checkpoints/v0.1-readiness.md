# Benos v0.1 readiness

## Release state

The approved v0.1 scope is implemented and verified. The core, DOM renderer,
compiler, Vite integration, diagnostics, documentation, browser coverage,
dashboard validation, and `create-benos` scaffolder are present. The packed
scaffolder verifies type-check, build, test, and lint in a fresh temporary
consumer project. No package was published.

All 133 repository tests pass, including type-level, compiler, DOM, consumer,
and `create-benos` coverage. The Playwright suite has 30 passing tests across
Chromium, Firefox, and WebKit. Build, lint, documentation-example,
public-import, generated-JSX, and bundle-size checks pass.

## Known performance gap versus Solid

The release measurement is the Phase 6b interleaved production trace: two
warmups and seven measured rounds through the same Chrome click-to-paint
boundary for every framework. Brackets show the observed minimum and maximum.
The complete record is in [`benchmarks/README.md`](../../benchmarks/README.md)
and [`phase6b-final-7.json`](../../benchmarks/js-framework-benchmark/results/phase6b-final-7.json).

| Workload           |                Benos (ms) |                Solid (ms) | Benos / Solid |
| ------------------ | ------------------------: | ------------------------: | ------------: |
| Create 1,000 rows  |    38.979 [38.933–40.550] |    24.498 [24.402–24.792] |         1.59× |
| Replace 1,000 rows |    41.685 [41.160–42.029] |    25.374 [25.276–26.340] |         1.64× |
| Update every 10th  |    12.863 [12.689–15.912] |    13.341 [13.308–13.520] |         0.96× |
| Select one row     |       1.275 [1.192–9.671] |       0.853 [0.774–0.984] |         1.49× |
| Swap rows          |       3.853 [3.725–9.469] |       2.786 [2.733–3.156] |         1.38× |
| Remove one row     |       4.635 [4.539–5.563] |       4.182 [4.143–4.205] |         1.11× |
| Create 10,000 rows | 360.152 [357.816–368.758] | 233.591 [231.637–235.998] |         1.54× |
| Append 1,000 rows  |    46.179 [45.961–48.041] |    34.737 [34.538–34.838] |         1.33× |
| Clear rows         |       6.113 [5.951–6.160] |       2.517 [2.477–2.563] |         2.43× |

Benos is close on update, select, swap, and remove, but remains behind Solid on
row creation, replacement, append, and clear. The largest measured gap is
clear. The earlier heap snapshot found more per-row JavaScript
objects in Benos, including event-record closures, owner/context objects, and
descriptor work; DOM insertion and disposal are also material. The benchmark
adapter remains idiomatic user code. These gaps are recorded rather than
masked, and the 4 KB/10 KB budgets remain unchanged.

## Performance decisions and open roadmap items

- The full-parent `<For>` clear path was retained in 6b after the controlled
  clear median improved from 6.877 ms to 6.113 ms.
- The stable-handler trial was tried and reverted: the benchmark adapter used
  inline closures, so there was no measured trace improvement; the temporary
  combined bundle reached 10,319 B.
- The two-ended `<For>` swap trial was tried and reverted: the controlled
  swap median changed from 8.006 ms before to 9.193 ms after.
- Further row-creation, filter, disposal, and allocation work that preserves
  the public API, documented ownership semantics, and bundle budgets.
- The completed v0.1 type and consumer gates remain recorded in
  `test-traceability.md`; future type-surface changes must preserve those
  generated intrinsic/ARIA types, generic control-flow contracts,
  `splitProps` literal-key inference, and the internal-subpath CI check.
- Post-v0.1 modules and tooling in [roadmap.md](../roadmap.md): router, forms,
  query, state evaluation, accessible UI primitives, the full `benos` CLI,
  DevTools, SSR/streaming, React interop, migration codemods, and other later
  investigations.

Package publication remains deferred. The `create-benos` package is tested
from packed archives but was not published.
