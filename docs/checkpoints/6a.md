# Phase 6a checkpoint

Status: complete. Phase 6b is now active.

## What changed

- Fixed the compiler's `mergeProps` helper import by exporting `mergeProps` from the supported compiler runtime entry point (`@benosjs/dom/internal`), and expanded the packed consumer fixture to compile and run the public helpers and control-flow components.
- Generated JSX intrinsic and attribute types from `@webref/elements`, `@webref/idl`, `aria-query`, and TypeScript's DOM declarations. The generated surface covers HTML, SVG, MathML, ARIA, data attributes, standard event names, and `output`; a CI freshness check prevents hand-edited drift.
- Published generic public types for `Show`, `For`, `Switch`, `Match`, `Dynamic`, `Portal`, and `ErrorBoundary` with `JSX.Element` returns. `splitProps` now preserves literal key arrays through a dedicated const-generic overload.
- Added `expect-type` coverage for helper return types, literal split groups, all control-flow component signatures, and representative HTML/SVG/MathML/ARIA attributes.
- Added a CI check that rejects application imports of `@benosjs/core/internal` and `@benosjs/dom/internal`.
- Removed type casts and assertions from `examples/dashboard` and confirmed its standalone typecheck succeeds. The existing ErrorBoundary reset callback was verified; the dashboard clears the external failure signal before calling reset because reset remounts the child but cannot mutate that signal itself.
