# Phase 6b checkpoint

Status: complete. Phase 6c is now active.

## What changed

- Added and kept the full-parent `<For>` clear fast path when the range fills its parent. It disposes row owners, clears the parent in one operation, and recreates the marker/fallback through the existing reconciliation path.
- Measured stable event-handler emission, the two-ended swap check, contiguous `Range.deleteContents()` removal, and a per-row disposal shortcut. The stable-handler and swap trials regressed or did not exercise the target workload; batched removal did not produce a repeatable trace or dashboard gain; no safe disposal shortcut preserved the ownership contract. Those trials were removed.
- The benchmark adapter stayed unchanged. The retained change uses 68 additional combined production gzip bytes; core remains unchanged.

## Interleaved production benchmark

Two warmups and seven measured rounds were run against Solid with every row included:

| Operation          | Benos median | Solid median | Ratio |
| ------------------ | -----------: | -----------: | ----: |
| Create 1,000 rows  |    38.979 ms |    24.498 ms | 1.59× |
| Replace 1,000 rows |    41.685 ms |    25.374 ms | 1.64× |
| Update every 10th  |    12.863 ms |    13.341 ms | 0.96× |
| Select one row     |     1.275 ms |     0.853 ms | 1.49× |
| Swap rows          |     3.853 ms |     2.786 ms | 1.38× |
| Remove one row     |     4.635 ms |     4.182 ms | 1.11× |
| Create 10,000 rows |   360.152 ms |   233.591 ms | 1.54× |
| Append 1,000 rows  |    46.179 ms |    34.737 ms | 1.33× |
| Clear rows         |     6.113 ms |     2.517 ms | 2.43× |

The dashboard filter slice measured 36.6 ms [32.2–43.9] for Benos and 11.2 ms
[9.8–16.5] for Solid. The CPU profile still points to owner disposal and DOM
removal as the main costs. A post-GC heap snapshot delta after creating 1,000
rows was 15.72 MB for Benos versus 11.43 MB for Solid; this includes whole-page
V8 objects and excludes native DOM memory. The detailed attribution and spread
are recorded in [benchmarks/README.md](../../benchmarks/README.md).
